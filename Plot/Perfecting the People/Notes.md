Key Aspects to a Good Murder Mystery:

- Have many suspects, each equally suspicious
- For some of the more plausible suspects, plan out how and why they would have commited the murder ("Fantasy Plot")
- Add new suspects which get added to the pool as the story goes on to replace those with alibis
- A plot twist should re-add multiple suspects including the murderer
- Have the murderer seem more innocuous and plain while the others seem more fleshed out. A quiet and reserved person fits this better.
- Make sure there are no clues which contradict the murder, and no clues which leave only the murderer. 
- The motive and resolution need to be satisfying. A good conclusion should leave the party thinking: "Ohhh so thats what happened" or "I Knew it!" rather than "Huh?" or "But it could have just as easily been this other guy"
- Once all the clues are in place and understood, there should only be one possible answer, assuming the clues are true and properly understood. Adding red herrings can make it feel like there is no proper answer, and adding false clues can make it seem like there is a single answer that is actually incorrect. Don't over rely on either of these though, as it is hard to remove red herrings and false clues after they are assumed.
